# JavaScript Deep Dive 🚀

A complete, self-built JavaScript syllabus — going from absolute basics to 
real-world, production-level concepts. Every topic includes hands-on practice 
problems (with edge cases and logical-thinking challenges) solved and tested 
before moving forward.

No shortcuts, no skipped fundamentals — just topic-by-topic, tested understanding.

## 📚 Progress

### ✅ Module 1: Foundations
- Variables & data types
- Operators
- Type conversion & coercion

### ✅ Module 2: Control Flow
- Conditionals (if/else, switch)
- All loop types (for, while, do-while, for...of, for...in)
- Loop control (break, continue)

### ✅ Module 3: Functions
- Function basics, arrow functions
- Default/rest/spread parameters
- Scope & hoisting
- Closures
- Higher-order functions & callbacks

### ✅ Module 4: Data Structures
- Arrays & array methods (map, filter, reduce, find, sort, etc.)
- Objects, methods, and `this`
- Deep vs shallow copy
- Sets & Maps

### ✅ Module 5: Advanced Functions & Patterns
- IIFEs
- Recursion
- Pure functions & immutability
- call, apply, bind

### ⏳ Coming Up
- Asynchronous JavaScript (Promises, async/await, Fetch API)
- Object-Oriented JavaScript (classes, prototypes, inheritance)
- DOM & Browser APIs
- Modern JS tooling
- Real-world projects & design patterns

## 📁 Structure

Each folder corresponds to a module, with individual files per topic containing 
explanations, code, and solved practice problems.
